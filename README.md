# SOS PC — Assistant de dépannage informatique

SOS PC est une application web gratuite pour aider les utilisateurs à résoudre des problèmes informatiques courants.

## Fonctionnalités
- Diagnostic guidé pour le Wi-Fi, un PC lent, une imprimante et le son.
- Liste d'étapes à cocher et barre de progression.
- Bouton pour recommencer.
- Interface adaptée aux téléphones et ordinateurs.

## Utilisation
Ouvrir `index.html` dans un navigateur. Aucun serveur ni compte n'est nécessaire.

## Technologies
HTML, CSS, JavaScript (sans bibliothèque externe).

## Structure
- `index.html` : structure de l'application.
- `style.css` : design.
- `script.js` : problèmes, étapes et interactions.

## Limites
SOS PC propose des conseils généraux et ne réalise pas de diagnostic automatique de l'ordinateur.

## Améliorations prévues
- Recherche par problème.
- Arbre de décision avec questions.
- Plus de catégories de dépannage.
